# Tarefa 2 – Sistema de Registo Electrónico de Utentes

## Sobre o projecto

Este projecto consiste no desenvolvimento de um sistema simples em Python destinado ao registo, identificação e acompanhamento de utentes nas unidades de saúde.

A aplicação permite organizar os dados pessoais dos pacientes e manter o histórico das consultas realizadas, facilitando a localização e consulta das respectivas informações.

## Funcionalidades

- Registar os dados pessoais dos utentes.
- Atribuir automaticamente um número único de registo.
- Associar o Número de Identificação Fiscal (NIF), quando aplicável.
- Consultar os dados dos utentes através do número de registo.
- Registar consultas, datas de atendimento e diagnósticos.
- Associar as consultas aos respectivos médicos.
- Consultar o histórico clínico dos utentes.
- Listar todos os utentes registados.

## Tecnologias utilizadas

- Python 3
- Listas e dicionários
- Funções
- Estruturas condicionais (`if`, `elif`, `else`)
- Ciclos de repetição (`for` e `while`)

## Objectivo

Aplicar os conhecimentos fundamentais da linguagem Python no desenvolvimento de uma solução informática que facilite a organização, identificação e consulta das informações dos utentes.
